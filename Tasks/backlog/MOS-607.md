Eliminate the `meeting-detect.sh` shell script. The Rust native module (`native/src/`) becomes the sole detection backend on ALL platforms including macOS. The JS-side classifiers and lifecycle state machine stay in TypeScript.

All of these must be true for the task to be complete:

1. `meeting-detect.sh` is deleted from the repo
2. `src/detector.ts` no longer spawns or references any shell script
3. `src/detector.ts` uses the Rust native module on ALL platforms (no `process.platform !== 'darwin'` guard)
4. `npm run build:ts` succeeds with zero errors
5. `npm test` passes (all existing tests, no regressions)
6. `cargo build` succeeds in `native/` directory
7. All changes are committed to the `dev` branch

## ARCHITECTURE CONTEXT

### How Detection Works (macOS, current state)

1. `meeting-detect.sh` streams macOS TCC log events for camera/mic access
2. Browser tab probe (AppleScript, every 2.5s) checks Chrome/Safari/Edge for meeting URLs
3. Native app probe (every 2.5s) checks running meeting processes + requires TCC mic signal within 60s
4. Classifiers (`browser-platform.ts`, `native-platform.ts`) map signals to platform names
5. Lifecycle state machine: first confident signal → `meeting_started`, 30s silence → `meeting_ended`

### How It Should Work After This Task

1. **Rust native module** streams TCC log events + enumerates processes (replaces shell script)
2. Browser tab probe stays in JS/AppleScript (or moves to Rust — your call based on Step 1 analysis)
3. Same classifiers, same lifecycle state machine — unchanged
4. No shell script anywhere in the pipeline
